# First Presbyterian Church of Paris, Texas

## Preview and review

Extract the ZIP and open index.html in your browser. Use the header links to visit all three pages. Keep the assets folder next to the HTML files.

Before publishing, confirm Sunday School at 9:30 a.m. and worship at 10:45 a.m. with the church. Update both index.html and about.html, then remove their provisional notices. Confirm the Food Pantry, Women's Association, Men's Monthly Breakfast, and Youth Group. Update get-connected.html with confirmed opportunities and any meeting or signup details the church wants to share, then remove its provisional notice. Review Jane Els's bio with the church.

The header uses the official PC(USA) two-color symbol. Publish under the congregation's authority and review the denomination's [symbol usage terms](https://pcusa.org/resources/pcusa-seal-symbol). Preserve the photo credits in the footer. The church exterior photo is by Renelibrary under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The other photos are illustrative stock from Pexels under the [Pexels License](https://www.pexels.com/license/).

## Publish on GitHub Pages

1. Open your GitHub repository and select **Add file → Upload files**. Upload the extracted files and the assets folder to the repository root. Keep index.html at the root. Include the empty .nojekyll file if your upload interface displays it.
2. Commit the files. In **Settings → Pages**, choose **Deploy from a branch**. Select **main** (or the branch where you committed the files) and **/ (root)**, then save.
3. Once GitHub finishes deploying, use **Visit site** in the Pages settings. Check all three pages and the directions link on a phone and a desktop.

[GitHub Pages setup documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
